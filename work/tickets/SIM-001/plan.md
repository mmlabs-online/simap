## Approach
1. **Pins and install.** Create `.mise.toml`, `.node-version`, `package.json` with `packageManager: pnpm@10.34.9`.
   Install at exact versions (no `^`) for `next` (latest stable 16.x patch on the day; Decision 1), `react` and
   `react-dom` (the 19.2.x that `next` peer-requires), `vitest` `5.1.0` (as tudocuatui). Caret ranges as tudocuatui for
   `typescript ^5.7.0`, `oxfmt ^0.76.0`, `tailwindcss ^4`, `@tailwindcss/postcss ^4`, `@types/node ^22`,
   `@types/react ^19`, `@types/react-dom ^19`; plus `server-only` (dependency). **No** `pg`, `jose`, ESLint, testing
   library, jsdom, coverage plugin or e2e runner in this ticket (D2; `pg` is SIM-002, `jose` is the auth ticket). If
   pnpm 10 reports ignored build scripts, approve only what `next build` needs via `pnpm.onlyBuiltDependencies` and
   record it in impl-log.
2. **Scripts.** `dev: next dev`, `build: next build`, `start: node .next/standalone/server.js`,
   `typecheck: next typegen && tsc --noEmit` (typegen makes route types and `next-env.d.ts` exist on a clean
   checkout), `format: oxfmt`, `format:check: oxfmt --check`, `test: vitest run`,
   `check:layers: node scripts/check-layers.mjs`. No `lint` script (Next 16 removed `next lint`; no ESLint per D2).
3. **App skeleton.** `next.config.ts`, `postcss.config.mjs`, `src/app/layout.tsx`, `globals.css`, `page.tsx`,
   `src/app/api/healthz/route.ts` + test. No `next/font` (it fetches at build time; fonts/icons are SIM-003). No
   `src/middleware.ts` / `src/proxy.ts`.
4. **R1 layering** (write this into CLAUDE.md R1 and the three `src/*/README.md`; enforce with
   `scripts/check-layers.mjs`):

   | Layer | Path | Holds | May import |
   |---|---|---|---|
   | api | `src/app/api/**/route.ts` | thin route handlers: verify bearer → validate input → one service call → map result/error to `Response` | server, lib |
   | pages | `src/app/**` except `src/app/api/**` | pages, layouts; org-data pages are client components that render `src/ui` and fetch `/api/*` (D4) | ui, lib |
   | ui | `src/ui/**` | components, hooks, `src/ui/api/` fetch client that attaches the bearer | lib |
   | server | `src/server/<module>/` (`service.ts`, `queries.ts`, tests); `src/server/http/` (bearer verify wrapper, single error shape) | server-only logic and SQL; every non-test `.ts` starts with `import "server-only"` | server, lib |
   | lib | `src/lib/**` | pure isomorphic code: types, DTOs, hand-written validators (`src/lib/validate/`, Decision 4) | lib only |

   Rule text for R1: "UI and page code never imports server code; route handlers under `src/app/api/**` are the only
   entry into `src/server/**` (D4). Imports across layers use the `@/` alias. `pnpm check:layers` enforces this."
   `check-layers.mjs` design (~80–100 lines, Node built-ins only): `findViolations(files: {path, source}[])` is pure;
   it extracts literal specifiers from `import … from "x"`, `import "x"`, `export … from "x"`, `import("x")`,
   `require("x")`; resolves `@/…` and relative specifiers to a `src/` path; classifies source and target by the table
   above; reports `{ file, specifier, rule }`. It also flags a non-test `src/server/**/*.ts(x)` whose first statement
   is not `import "server-only"`. Files under `src/test/**` and non-code files are skipped. The CLI part (run only when
   the file is the entry point) walks `src/` with `fs.readdirSync(…, { recursive: true })`, prints one line per
   violation and exits 1. Known gap (documented in the script header): non-literal dynamic imports.
5. **CI** (`.github/workflows/ci.yml`), pattern of tudocuatui `ci.yml` L1-35 and L47-48 without the Postgres service,
   migrate smoke and `image` job: triggers `pull_request` + `push` to `main`; `permissions: contents: read`; same
   concurrency block; one `ci` job on `ubuntu-latest`: checkout@v4 → pnpm/action-setup@v4 (reads `packageManager`) →
   setup-node@v4 (22, `cache: pnpm`) → `pnpm install --frozen-lockfile` → `pnpm typecheck` → `pnpm check:layers` →
   `pnpm test` → `pnpm format:check` → `pnpm build` → `test -f .next/standalone/server.js`. No secrets used.
6. **High paths.** In `.github/risk-tiers.yml` `high:` and the `.claude/loop.config.md` mirror, keep every existing
   entry and add: `next.config.*` (Decision 3), `src/middleware.*`, `src/proxy.*` (request interception, Next 16
   renamed middleware to proxy), `src/server/identity/**` (token verifier, D4), `src/server/http/**` (bearer wrapper +
   error shape), `scripts/check-layers.mjs` (guards R1). Remove the "Revisit when the scaffold ticket fixes the code
   layout" comment line. Do not touch `.github/scripts/risk_tier.py` (kit-managed).
7. **CLAUDE.md.** Replace the TODO description with a one-paragraph summary of spec §1. Stack: replace the two
   Planned/TODO lines with the actual stack (Next.js 16 App Router, TypeScript, Tailwind v4, oxfmt, Vitest; `pg` +
   tudocuatui migrator arrive in SIM-002). Commands: install, dev, typecheck, check:layers, format, format:check, test,
   build, start. R1 as in step 4. Leave R2–R5 unchanged.
8. **loop.config.md.** Prepare: `pnpm install --frozen-lockfile`; keep the local-Postgres TODO and tag it "(SIM-002)".
   Checks: format `pnpm format:check`; lint / typecheck `pnpm typecheck && pnpm check:layers`; test `pnpm test`; build
   `pnpm build`. Replace "Until the scaffold ticket lands…" with nothing. Bug test level: "Vitest unit test". `/solo`
   limits: drop "and anything before the scaffold ticket defines the layout". High paths mirror per step 6.
9. **`.env.example`**: header comment ("Names only, never values (R3). `DATABASE_URL` arrives with SIM-002.") and
   `PORT=` (read by the standalone server). Nothing else.
10. Run every check locally from a clean state; then `pnpm format` once so `format:check` passes.
